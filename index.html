About — 전면

만드는 것: AI 코딩 에이전트가 실제 일을 하게 만드는 인프라. 문서 검색(alcove), 논문 리서치(research-agent), 에이전트 실행 하니스(epic-harness), 책 출판(Velith)까지 — 각 도구는 CLI와 MCP 서버로 동시에 동작하고, Claude Code·Codex·Cursor 같은 5개 이상의 에이전트 호스트에서 플러그인으로 설치된다.

방식: 단일 Rust 바이너리, SQLite + FTS5, 정적 사이트. 빌드 스텝과 백엔드 없이 배포되는 것을 선호한다. 리서치는 수집 → 갭 분석 → 팩트체크 → 발행까지 추적 가능한 파이프라인으로 운영하고, 그 결과물이 아래 Research Sites다.

이전 경력: 커머스, 규제 핀테크, 크립토, 보안 — AWS/GCP 위에서 결제·정산·보안 시스템을 운영했다. 그때의 습관이 지금 도구 설계에 남아 있다. 신뢰 경계 명시, 실패 시 되돌릴 수 있는 구조, 규정 준수 로그.
