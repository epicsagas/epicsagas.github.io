About

What I build: infrastructure that makes AI coding agents actually do work. Document retrieval (alcove), paper research (research-agent), agent execution harness (epic-harness), book publishing (Velith) — each tool runs as both a CLI and an MCP server, and installs as a plugin on five or more agent hosts.

How I build: single Rust binaries, SQLite with FTS5, static sites. I prefer things that deploy with no build step and no backend. Research runs as a trackable pipeline — collect, gap-analyze, fact-check, publish — and its outputs are the Research Sites below.

Before this: commerce, regulated fintech, crypto, and security — payment, settlement, and security systems on AWS/GCP. Habits from that era still shape how I design tools: explicit trust boundaries, structures you can roll back when they fail, compliance logs.
